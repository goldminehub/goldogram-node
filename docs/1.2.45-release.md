# goldogram-node 1.2.45

Notify-only GitHub release. Ships goldogram-core with trusted sync checkpoint **963646** (`106df162…f71998`).

Heights below the pin use the same trusted-seed bootstrap as the old 502600 window (no PoW / no prev re-hash). The pin hash is mandatory. Above the pin, full validation is unchanged.

This is required because goldmine’s canonical chain has 94 historical parent-replacement breaks after 502600 (including 946340). See `goldogram-protocol/docs/assurance/node-1.2.45-release.md`.
