# goldogram-node 1.2.49

Hotfix for the 1.2.48 Windows dialog `[unhandledrejection] TypeError: Cannot read properties of null (reading 'style')` in `showMinerSyncBanner`. Isolated/fork status paints no longer destroy `#mining-sync-bar` / `#mining-sync-text`. Periodic `fetchStatus` resolves those nodes at call time and returns if they are absent, so the fatal overlay is reserved for real failures.
