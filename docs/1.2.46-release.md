# goldogram-node 1.2.46

Connect-by-address is the default for client-custody accounts. The node mines to a checksum-validated Master wallet address and reads balance via the public API. No password is stored.

Legacy username/password remains for existing accounts. A client-custody login returns `client_custody_use_address` instead of `invalid_credentials`.
